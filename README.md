## 🚀 Sobre mim

Olá! Sou **Thales Maggot**, mais conhecido como **MrMadara**.

Sou desenvolvedor, técnico em TI e entusiasta de tecnologia, com experiência em desenvolvimento de software, configuração e administração de servidores, desenvolvimento de games e criação de soluções para diferentes ecossistemas.

Minha trajetória envolve desde **desenvolvimento de aplicações e plugins** até **infraestrutura, servidores de jogos, sistemas Linux/Windows, segurança, automação e ferramentas para comunidades**.

Gosto de entender como as coisas funcionam por baixo do capô e, quando não existe uma ferramenta que resolve o problema, normalmente a solução é construir uma.

Também tenho interesse constante em aprender novas linguagens, experimentar diferentes sistemas operacionais, estudar novas tecnologias e contribuir com projetos de código aberto.
